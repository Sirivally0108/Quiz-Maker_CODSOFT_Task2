# Online Quiz Maker — Frontend

React + Vite single-page application. See the root `README.md` for full
setup instructions. Quick reference:

```powershell
npm install
npm run dev       # starts the dev server on http://localhost:5173
npm run build     # builds for production into dist/
```

Copy `.env.example` to `.env` and set `VITE_API_URL` to point at your
running backend (defaults to `http://localhost:5000/api`).
